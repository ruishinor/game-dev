# Personal archival relics — initial rare-loot slice

Vault Memory Foil (rare) and Lattice Witness Seal (very rare) are intentionally visible playtest collectibles, with unique original item illustrations, named quality, private loot presentation, and an inventory Relics filter. Neither is required for progression, gives combat power or can be sold, purchased, or converted into currency. Each character may own at most one of each. Their distinct archival descriptions provide a reason to inspect the collectible; no unimplemented exchange or title feature is implied.

The existing eligible encounter-credit rule applies (including support credit); each Warden death grants at most one independent rare outcome per credited local recipient. The server's independent cryptographic draw does not alter existing equipment rolls or deterministic simulation RNG. Already-owned outcomes are omitted; no reroll or duplicate. Corpse generation, range, line of sight, owner entitlement and atomically validated stack collection remain enforced. No new world entity or public announcement of acquisition. Browser code includes only approved presentation identities and rarity labels, not odds or source tables. Public development Git remains inspectable; exact thresholds are not confidential in this repository.

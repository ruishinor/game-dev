# Lattice arrival hall
A real open-sided arrival facility surrounds the existing spawn location. Its four collision-bearing columns, canopy, floor guidance and interactive orientation terminal connect new-character arrival to existing directives, controls, equipment and fabrication. Orientation is optional, records an idempotent per-character receipt, consumes no items and grants no advantage. Existing character creation, respawn and tutorial/quest semantics remain. This is not an enclosed cinematic creation suite; live appearance preview is separately tracked in #97. Visual fit and first-user playtesting still required.

## In-world customization increment
The arrival hall now has side enclosure walls, retains forward/rear exits, and offers persistent cosmetic appearance selection from its physical terminal. Appearance changes are validated against the existing shared options, proximity, line of sight, combat/production and cooldown server-side. The owning and observing clients rebuild the actual player model on authoritative appearance metadata change, preserving identity and interpolation. The existing account/login creation remains as a compatibility fallback; this does not replace name/class selection with an isolated mandatory cinematic. No additional races or facial morphs are claimed.

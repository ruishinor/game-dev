# REC-01A — Optional modular route for an existing weapon

This is a narrow, independent gameplay increment toward REC-01, not the full modular-weapon program. The Sanctum Quartermaster sells a pulse containment housing. A Rogue Sentinel can already drop a Field Vector Array through its existing server-only personal equipment loot roll; dismantling an unequipped owned array at the Workshop produces a recovered vector matrix. Conductive fibres become a dormant pulse cell; combine the matrix and cell into a pulse module. A commissioned Brineworks Engineering station can combine the module and housing with existing advanced materials to build the **existing QL5 Dense Pulse Core**, using the same Resonance/Kinetics prerequisites. The alternative legacy Dense Pulse Core recipe remains untouched.

No new enemy-drop probability, drop item table, vendor identity, world region, hidden encounter content, weapon stats, model, client authority, or Longpoint acquisition/animation was changed. Components are ordinary bounded persisted materials, rendered using existing generic inventory art until individual illustrations are delivered. Vendor transaction and corpse loot still use the established server-side ticket/revision, owner, range and one-time checks. Extraction irrevocably consumes an unequipped recovered device, and the Workshop shows this cost. This provides a full but optional source → purchase → extraction → fabrication → equipment loop without introducing a visually unrepresented weapon.

**Still outstanding:** multiple genuinely new assembled weapons, unique illustration/mesh/hand-grip families, specific specialist-vendor inventories beyond the currently established quartermaster, research/quest acquisition, rare blueprint gating, economy balance and human play acceptance. Do not treat REC-01 as complete or merge historic #93 wholesale. The isolated #139 Expanse/Foundry loot and vendor track is out of scope.


**Visual delivery:** Four component identities use distinct, authored object portraits in `client/src/catalogue-portraits.js` (including the existing pulse-module artwork); these are visible in Workshop and Inventory. This is still a vector inventory presentation, not a newly sculpted 3D weapon or visual-acceptance claim.

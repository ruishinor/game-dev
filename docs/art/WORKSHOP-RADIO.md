# Workshop onboarding and radio transmission

Tutorial is non-modal, first-open guided and replayable, persisted only locally. It changes tab/preview state, never automatically equips or fabricates. All recipe materials, consumed targets and results use static distinct vector item art shared with inventory and Codex; these are industrial schematic illustrations, not final photoreal item renders. Existing recipes, crafting checks and transactional behavior remain unchanged.

Remote transmissions: private authored server messages for Kernel directive advancement, field archive and Kestrel recorder alongside existing log; unrelated combat, loot and player chat are not voice inputs. A separate portrait, transcript, signal animation, local voice replay and mute control; bounded duplicate-safe pending queue and reset on world clear. The anonymous Kestrel archive uses an illustrative researcher portrait, not a newly named character. Speech is optional OS/browser local English synthesis only (not a prerecorded actor performance). No cloud voice, microphone, audio upload or external dependency. If local speech is unavailable or autoplay fails, the complete transcript remains. Wave animation indicates playback state, not measured audio amplitude; reduced-motion static. UI is DOM rather than GPU VFX to avoid burdening rendering/visibility. No claim of final art, sound or actual voice verification. Tests cover private event and queue; browser coverage checks presentation and gameplay unaffected.

# REC-04A — Recovered compact weapon geometry

Three source-pinned CC0 Quaternius compact firearm GLBs (Field, Tuned, Dense), formerly stranded in old PR #93/#96, are copied byte-for-byte into `client/weapon-assets/` with explicit provenance in `assets/weapon-sources.json`. Field and Tuned have dedicated sizes, muzzle/control anchors, a single carried weapon at a time, bounded cosmetic recoil and a presentation-only aim fit. Dense is retained as a verified donor file only, not a playable firearm: the current Dense Pulse Core is a Vanguard melee equipment path and must not silently become a gun. The Field/Tuned visual tokens are allowlisted only for currently owned and equipped weapons on ranged-auto professions. No Dense token is issued. No weapon modifiers, QL, classes, acquisition, damage, range, combat scheduling, server-sourced animation or travel is changed.

The previously merged original `client/assets/longpoint.glb` and `createLongpointPresentation` remain untouched and selected by the existing `longpoint` visual token. These donor models are historical, small licensed assets; they are **not** art-direction or high-fidelity acceptance. Field/Tuned still need independent in-world visual inspection for proportions, grip, muzzle alignment and both body frames. Scripted source validation is necessary but insufficient for that.

The client preloads two small active models only when GLB rendering is enabled, shares immutable meshes/materials, and uses the old safe procedural behavior if a donor is unavailable. Presentation-only aim/recoil cannot deal damage, alter the authoritative target or trigger extra server events. A follow-on needs actual gameplay screenshots for all classes, movement, casting, death, quality levels and observed players. Do not merge old #93/#96 wholesale and do not touch Claude's reserved Expanse/Foundry.

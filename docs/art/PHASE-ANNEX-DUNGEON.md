# Phase Annex — three-room dungeon candidate

Extends the existing calibrated Phase Scar travel candidate, not the cosmetic anomaly. The Arrival Gallery is the return chamber; offset physical passages connect the Relay Workshop (two hostiles) and Null Chamber (sentinel and warden). Interior bulkheads share the server's movement and combat sightline checks. Lighting and floor treatments differentiate spaces. Entry retains calibration and safe-phase checks; return retains disengagement, shared consequences and safe reconnect. Existing loot tables remain authoritative; no extra reward, reset-on-entry farm, raid instance, or new boss behaviour is claimed. The warden uses the existing archetype; balance, navigation around corners, full two-client playthrough and artistic inspection remain required.

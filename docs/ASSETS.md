# Assets: provenance and pipeline

Every third-party visual source the asset build uses is listed in
[`assets/sources.json`](../assets/sources.json) with its creator, licence,
source URL, size, SHA-256 and acquisition date. Nothing is used that is not in
that ledger, and the build refuses an asset that names an unknown source.

Modified status: every visual file in `client/assets/manifest.json` is a derivative

live in `.asset-cache/` (git-ignored) and are re-downloadable from the ledger.

chibi/toy proportions that fit neither Attunement nor Red Rucker); Mixamo
(needs an Adobe login and its redistribution terms are unclear); anything from
World of Warcraft or Anarchy Online (proprietary; reference only).

## Pipeline

```bash
npm run assets:fetch     # download sources into .asset-cache/, verify SHA-256, unpack
npm run assets:build     # recipe -> client/assets/*.glb, tex/*.webp, manifest.json
npm run assets:preview   # contact sheets through the real game loader -> docs/evidence/assets/
```

`assets:build -- <id> …` validates the output IDs and fetches only the relevant sources. The Sanctum threshold and Sporefield colonies use pieces already in the committed kits. Audio has a separate [voice credit record](art/VOICE-CREDITS.md). The built files are
committed, so playing the game never needs these commands.

- **`assets/recipe.mjs`** — what to build: humanoid bodies and clips, clothing
  shell definitions, kit piece lists, standalone textures. Data only.
- **`tools/assets/build.mjs`** — runs the recipe with
  [glTF Transform](https://gltf-transform.dev/): merge pieces into bundles,
  de-duplicate textures and materials, resize textures to WebP, compress
  geometry and animation with Meshopt, write `manifest.json` (URL, content
  hash, size, triangles, pieces, clips, source ids).
- **`tools/assets/lib/humanoid.mjs`** — merges both animation libraries onto
  one skeleton (a bone rename, checked at build time), gives the body a
  positional UV atlas, and cuts clothing/armour shells from the body mesh.
- **`client/src/assets.js`** — runtime loader: one download and decode per
  bundle, shared geometry/textures, per-entity skeletons.

Current output (2026-11-16): 13 files, 5.97 MB total.

| textures | 0.51 MB | — | Terrain (2) and painted outfits (6) |

"Before compression" is the same content written as an uncompressed GLB with
each piece carrying its own PNG textures.

Choices, measured rather than assumed: Meshopt (decoder ships with three.js,
compresses animation too) over Draco; WebP over KTX2 (KTX2 would cut GPU
memory but needs an external encoder and a transcoder larger than several of
these bundles — revisit if texture memory becomes a problem).

## Spindle rigid companion

Spindle is original procedural art, built independently with
`npm run assets:build -- spindle`. Its shipped GLB contains full-detail
(33,796 triangles) and distance (9,494 triangles) scenes sharing material and
tool geometry. The runtime keeps the articulated pose continuous across camera
LOD changes. See [the production and validation record](art/SPINDLE.md) for
provenance, integration, metrics and outstanding browser validation.

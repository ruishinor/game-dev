# Neural audition build

This isolated build uses official [Kokoro](https://github.com/hexgrad/kokoro) 0.9.4 and [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M/tree/f3ff3571791e39611d31c381e3a41a3af07b4987) v1.0, published under Apache-2.0. The upstream [voice card](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md) provides estimates of voice training quality, not an artistic assessment. Male candidates am_michael/am_fenrir; female af_heart/af_bella. Compare two representative lines per identity across both candidates. No voice cloning or third-party dialogue. No model files bundled with the game.

Run `python tools/voice/audition.py` from an environment with Python 3.11, Node, FFmpeg (libmp3lame), eSpeak NG, kokoro==0.9.4, soundfile==0.13.1, and CPU torch==2.7.1. Downloads only pinned official model files; subsequent `--offline` runs use the cache (other dependency linguistic resources must also be installed/cached). `--all` generates all catalog lines using provisional defaults, not approval. Output directory must not already exist. The voice workflow produces a private, temporary review artifact only; no repository write token, deployment, or game asset promotion. Dependency transitives and OS packages are not fully locked; package versions and model/voice hashes are recorded. Upstream model license is not proof of complete voice provenance or legal clearance. Verify output-use rights, any voice restrictions and licensing notes before redistribution.

Each take has a clean 24 kHz mono PCM WAV and a channel-filtered MP3 with one-pass loudness normalization targeting -18 LUFS/-1.5 dBTP. One-pass targets are not independently measured compliance. Decode and signal checks are technical only. Compare intelligibility, pronunciation, emotional credibility, cadence, identity, profile filtering and fatigue by listening. No claims of audible quality. Auditions remain unapproved even if CI passes.
